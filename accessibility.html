Accessibility features

These are the accessibility-related capabilities currently described for Lumidoku.

Large text

Lumidoku supports larger text to make information easier to read and reduce visual strain.

TalkBack support

Lumidoku includes support for Android TalkBack, allowing users who rely on screen-reading technology to interact with the app.

Light theme

A light visual theme provides a bright interface for players who prefer a traditional light appearance.

Dark theme

A dark theme provides an alternative visual presentation for players who prefer darker interfaces.

English

English is supported throughout the Lumidoku experience.

Hindi

Hindi is supported to make Lumidoku accessible to more players.

Using Lumidoku with TalkBack

Lumidoku supports Android's TalkBack accessibility service. If TalkBack is enabled on your device, use the standard Android accessibility gestures and controls to navigate supported Lumidoku elements.

TalkBack behavior can vary depending on your Android version, device manufacturer and accessibility settings.

  1. Open your Android accessibility settings.
  2. Enable TalkBack if it is not already enabled.
  3. Open Lumidoku and navigate through the available controls using TalkBack.

Our accessibility approach

  • Keep important information readable and easy to find.
  • Support different visual preferences through light and dark themes.
  • Provide larger text for improved readability.
  • Support Android's TalkBack experience.
  • Provide both English and Hindi.
  • Continue improving the experience based on real player feedback.

Accessibility limitations

Accessibility support can vary across Android versions, device manufacturers, screen sizes and system accessibility settings. Some interactions or content may not behave identically on every device. If you encounter an accessibility problem, please report it so we can investigate and improve the experience.

Found an accessibility problem?

Tell us what happened, which Android device you use, and which accessibility feature you were using. Your feedback helps us make Lumidoku better.
